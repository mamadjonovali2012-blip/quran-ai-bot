# QuranAI Bot 🤖📖

Telegram-бот для чтения и изучения Корана с AI-помощником.

## Возможности

- 📖 **Чтение Корана** — все 114 сур, арабский текст + перевод
- 🔍 **Поиск по тексту** — поиск аятов по ключевым словам
- 📖 **Тафсир** — толкование к каждому аяту
- 🔊 **Аудио** — воспроизведение сур и аятов (8 чтецов)
- 🗣 **Транслитерация** — произношение арабского текста
- 🌍 **Переводы** — несколько переводов (Кулиев, Османов, Sahih Intl. и др.)
- 🤖 **AI-помощник** — отвечает на вопросы об исламе, Коране, сунне
- 📑 **Закладки** — сохраняйте любимые аяты
- 🌐 **Мультиязычность** — русский, английский, арабский

## Команды

| Команда | Описание |
|---------|----------|
| `/start` | Запуск бота |
| `/quran` | Выбор суры |
| `/search <текст>` | Поиск по Корану |
| `/ai <вопрос>` | Вопрос к AI-помощнику |
| `/audio <сура> [аят]` | Аудио-воспроизведение |
| `/bookmarks` | Закладки |
| `/language` | Смена языка |
| `/settings` | Настройки |
| `/help` | Справка |

Также есть кнопки:

- `/AI` — режим AI-ассистента
- `/Quran` — режим чтения Корана

## Установка и запуск

```bash
# 1. Установите зависимости
npm install

# 2. Создайте файл .env из примера
cp .env.example .env
# Заполните BOT_TOKEN (токен от @BotFather)

# 3. Запустите бота
npm start
```

### Настройка AI-помощника (опционально)

Для работы `/ai` укажите в `.env`:

```env
AI_API_KEY=ваш_ключ
AI_BASE_URL=https://openrouter.ai/api/v1
AI_MODEL=openrouter/auto
```

Без ключа бот работает в полном объёме, кроме AI-режима.

## Стек

- **Node.js** (>= 18)
- **Telegraf** — библиотека для Telegram Bot API
- **api.alquran.cloud** — текст Корана, переводы, тафсир
- **cdn.islamic.network** — аудио
- **OpenRouter API** (опционально) — AI-помощник
