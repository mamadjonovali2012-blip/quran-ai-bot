# QuranAI Bot 📖

Мощный Telegram-бот для чтения и изучения Корана. Работает 24/7 на Render.com.

## Возможности

- 📖 **Чтение Корана** — все 114 сур + 30 джузов, арабский текст и перевод
- 🔍 **Поиск по тексту** — по ключевым словам (команда `/search` и инлайн-режим)
- ⚡ **Инлайн-режим** — `@QuranAIBot <текст>` в любом чате
- 📖 **Тафсир** — толкование к каждому аяту
- 🔊 **Аудио** — 8 чтецов, суры и отдельные аяты
- 🎲 **Случайный аят** — команда `/random`
- 📅 **Аят дня** — страница `/daily`
- 🔖 **Закладки** — сохраняйте любимые аяты
- ◀️▶️ **Навигация** — листайте аяты вперёд/назад
- 🌐 **Переводы** — Кулиев, Sahih Intl., Pickthall, транслитерация
- 🌍 **3 языка** — русский, английский, арабский

## Команды

| Команда | Описание |
|---------|----------|
| `/start` | Запуск |
| `/quran` | Навигация: суры / джузы |
| `/random` | Случайный аят |
| `/search <текст>` | Поиск по Корану |
| `/audio <сура> [аят]` | Аудио |
| `/bookmarks` | Закладки |
| `/language` | Смена языка |
| `/help` | Все команды |

## Запуск локально (polling)

```bash
npm install
copy .env.example .env   # впишите BOT_TOKEN
npm start                # WEBHOOK=false → polling
```

## Деплой на Render.com (вебхук)

1. Репозиторий на GitHub
2. `render.yaml` подключит сервис автоматически
3. Переменные окружения: `BOT_TOKEN`, `WEBHOOK_URL`, `WEBHOOK_SECRET`
4. Deploy — бот получает обновления через вебхук

## Стек

- **Node.js 18+** + **Telegraf 4**
- **api.alquran.cloud** — текст, переводы, тафсир
- **cdn.islamic.network** — аудио
- **Render.com** — хостинг (встроенный health-check)
