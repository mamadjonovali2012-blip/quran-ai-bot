# QuranAI Bot 📖

Telegram-бот для чтения и изучения Корана.

## Возможности

- 📖 **Чтение Корана** — все 114 сур, арабский текст + перевод
- 🔍 **Поиск по тексту** — поиск аятов по ключевым словам
- 📖 **Тафсир** — толкование к каждому аяту
- 🔊 **Аудио** — воспроизведение сур и аятов (8 чтецов)
- 🌍 **Переводы** — несколько переводов (Кулиев, Османов, Sahih Intl. и др.)
- 📑 **Закладки** — сохраняйте любимые аяты
- 🌐 **Мультиязычность** — русский, английский, арабский

## Команды

| Команда | Описание |
|---------|----------|
| `/start` | Запуск бота |
| `/quran` | Выбор суры |
| `/search <текст>` | Поиск по Корану |
| `/audio <сура> [аят]` | Аудио-воспроизведение |
| `/bookmarks` | Закладки |
| `/language` | Смена языка |
| `/settings` | Настройки |
| `/help` | Справка |

## Установка и запуск

```bash
# 1. Установите зависимости
npm install

# 2. Создайте файл .env из примера
cp .env.example .env
# Заполните BOT_TOKEN (токен от @BotFather)

# 3. Запустите бота
npm start
```

## Деплой на Render.com

1. Загрузите проект на GitHub
2. На render.com создайте **New Web Service** и подключите репозиторий
3. Render сам определит конфиг из `render.yaml`
4. Укажите переменную окружения `BOT_TOKEN` в настройках сервиса
5. Готово — бот работает в облаке, доступ к Telegram не нужен с вашей машины

## Стек

- **Node.js** (>= 18)
- **Telegraf** — библиотека для Telegram Bot API
- **api.alquran.cloud** — текст Корана, переводы, тафсир
- **cdn.islamic.network** — аудио
